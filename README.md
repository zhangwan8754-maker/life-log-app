# Life Log · App

Life Log 的网页前端（PWA），读写你**私有**的 `life-log` 数据仓库。

- 纯静态，没有后端：浏览器直接用你自己的 GitHub 令牌读写仓库里的 Markdown。
- 本仓库只有代码，不含任何记录。

## 一个循环，四个主页

App 围绕数据仓库的那个循环来组织：**捕获 → 记忆 → 复盘 → 迭代**。底部切换（桌面端在左侧栏），内容放在淡雾蓝底色上的白色圆角分组里。

| 主页 | 循环里的哪一步 | 做什么 |
|---|---|---|
| **今天** | 捕获 | 只有三块：要做的事（含逾期）、日记、速记（投入并在速记里，一行小结）。情绪和精力收在日期那一行。点日期可以翻到任意一天 |
| **计划** | 行动 | 收件箱、日程（逾期、未来 14 天、以后）、各个项目（带进度小饼图和目标）、将来 |
| **记忆** | 记忆 | 时间线（过去的每一天、「那时的今天」）、速记（可只看「学到 / 问题」）、模式（AI 记下的假设，由你裁决）；顶上搜索速记、日记 |
| **复盘** | 复盘与迭代 | 主页只留入口：每周复盘流程（回顾 → 清理 → 反思 → 计划）、各个 AI 的建议、数据（本周数字、每周目标、学习时间、30 天趋势、年度热力图）、我是谁、历史复盘、复制给 AI、设置 |

**速记的种类**：记速记时可以选「想法 / 学到 / 问题 / 投入」。后三种会在前面加上 `学到：` 这样的开头，复盘时能单独找出来。

**投入**：时间花在了哪。在「今天」点「记投入」，选一个名称、点一个时长就记下了（`投入：英语 1h`）；「今天」显示一行小结，「复盘 · 数据」按名称汇总，每周复盘的数据里也会写上。每天都要做的事用它来记，不要写成永远勾不掉的待办。

**计时**：不知道会学多久时，在「记投入」里选好名称，点「开始计时」。「今天」页最上面出现一张计时卡片，点「结束并记下」就写成一笔投入（`投入：数学 47min`）；点错了可以撤销，撤销后接着计时。休息时点「暂停」，暂停的时间不算进投入。别的页面上，「今天」那一格右上角有个小点表示正在计时。计时只存在这台设备上，关掉页面也在走。超过 4 小时多半是忘了结束，App 会先问实际学了多久。

**每周目标**：每科一周打算投入几小时。在「复盘 · 数据」里点「设目标」（或「我是谁 · 方向 · 每周投入」），写进 `me.md`：

```markdown
## 方向
### 每周投入
- 数学 10h
- 英语 14h
```

「今天」页多一行本周进度，「数据」和每周复盘里是进度条，复盘文件的「数据」里也会写上（`- 每周目标：数学 2h/10h、英语 2h/14h`）。一笔投入算进名称相同、或者是它开头的那个目标：「英语语法」算进「英语」。

**记忆层**（数据仓库的 `memory/`，由 AI 维护）：
- 模式：每条是带证据和反例的假设。点开可以裁决为「观察中 / 成立 / 推翻」，App 只改那一行状态，并记下是你哪天定的。
- 建议：**每个 AI 一栏**。`memory/proposals/claude.md`、`memory/proposals/deepseek.md`…… 一个文件对应一个 AI，「复盘」主页每个 AI 一行，点进去各看各的、各划各的，互不覆盖。做完或不采纳就划掉。任何能读写这个仓库的 AI 只要按数据仓库 `AGENTS.md` 的约定写自己的那个文件，就会自动出现在这里。
- 大事记：只读地显示，里面的日期可以点进那一天。

**学习时间**（「复盘 · 数据」）：
- 本周每天一根竖条，今天那根标出来；下面一行是日均、几天有投入、连续几天（今天还没记不算断）。
- 按科目：每科多少小时、这周有几天学了它。
- 最近 8 周每周的合计。
- 年度热力图可以切「投入 / 情绪 / 精力」，默认看投入，一格是一天，6 小时以上是最深的颜色。

**复制给 AI**（「复盘」主页）：把这一周复盘要用的东西打成一段文字，粘贴给任何一个 AI。里面有：
- 复盘的规则，以及今天是周几（这一周没过完的几天不算缺记录）；
- 「我是谁」全文；
- 数据：每天一行（情绪、精力、日记字数、投入）、每科几小时几天、对每周目标、和上周比；
- 上周说的下一步；
- 记忆：模式账本连同证据和反例、大事记、各个 AI 已经提过还没处理的建议（避免重复）；
- 每天的日记和速记原文、没完成的待办；
- 回答的格式：按「事实 / 模式 / 下一步」三段写，可以直接贴进每周复盘对应的三步。

**每周复盘**的第一步会先列出上一期「下一步」里写的每一条，「反思」那一步可以一键把它们带进「事实」，逐条写做了没有。

**我是谁**（在「复盘」里）：`me.md` 按五个问题组织，每一栏单独编辑。
- 现在：只写事实
- 在乎：让我有劲的 / 耗我的 / 好的一天（自己的尺子）
- 方向：这学期 / 每周投入（可选，见上）/ 毕业时 / 更远
- 做法：验证过的 / 借来的（读到、听到，还没自己试过）
- 还没想清楚

每周复盘会拿「方向 · 这学期」来对照。

**操作**
- 右下角 **＋**（桌面按 `/`）：快速新建待办（选哪天做、放进哪个项目）或速记（选种类）。
- 勾掉的任务会停留约 2 秒再淡出，这期间再点一下就能反悔。
- 任务**右滑完成、左滑改期**。点开可以改文字、排日期、移到别的项目、删除；删除可以撤销。
- 点开任意一条速记可以改、删。

## 数据格式

所有记录都在数据仓库里，`AGENTS.md` 有完整说明。待办的格式：

```markdown
## 收件箱
- [ ] 买牛奶 @2026-11-06          ← @日期 = 计划哪天做
## 读书计划                      ← 其余任何 ## 标题都是一个项目
> 今年读完 24 本                 ← 可选：项目目标
- [x] 读完《人类简史》 ✓2026-11-01 ← 完成后留在原项目里
## 将来
```

旧版的 `现在 / 之后 / 完成` 格式，在第一次打开新版时会自动升级。

速记的三个可选开头（每日文件的 `## 速记` 里）：

```markdown
- 21:30 投入：英语 1h，读书 1h，跑步 40min   ← 名称 + 时长，逗号隔开
- 22:05 学到：先列提纲再动笔
- 22:10 问题：要不要换到早上跑步？
```

App 读写 `me.md`、`todo.md`、`days/`、`reviews/`、`memory/`；对 `memory/` 只做两种写入（改模式状态、划掉某个 AI 的一条建议），其余由 AI 维护。

## 同步机制

每次修改都是一个**可重放的操作**，比如追加速记、设置 mood、勾选某条待办。修改先存进本机队列；联网时取远端最新版本，把队列里的操作重放上去，再提交。因此：

- **离线也能记**，联网后自动提交。
- **多设备同时改不会互相覆盖。**
- 内容按 git sha 缓存在 IndexedDB 里，打开就能看到，之后只下载有变化的文件。

## 部署

推送到 `main` 后，GitHub Actions 会自动测试、构建，并发布到 GitHub Pages（Settings → Pages → Source 选 GitHub Actions）。

## 首次使用

1. [新建 fine-grained token](https://github.com/settings/personal-access-tokens/new)：
   - Repository access 只选 `life-log`
   - Contents 设为 **Read and write**
2. 打开网页，填用户名、仓库名和令牌。令牌只存在这台设备上。
3. 安卓：Chrome 菜单 →「安装应用」。iPhone：Safari 分享 →「添加到主屏幕」。

## 开发

```bash
npm install
npm run dev
npm test               # 单元测试：待办模型、迁移、复盘统计、Markdown 读写、记忆层
npm run build
npm run e2e            # 端到端测试：真实浏览器 + 内存版假 GitHub（需全局安装 playwright）
npm run e2e -- --shots # 同时生成 Pixel 7 与桌面、亮色与暗色的截图到 tests/shots/
npm run e2e -- --board # 只渲染「今天」页的背景深浅对比图
npm run icons          # 由 public/icon-v3-full.svg 生成浏览器图标和各尺寸 PNG（需全局安装 playwright）
```

### 代码结构

| 位置 | 内容 |
|---|---|
| `src/lib/` | 与界面无关的部分 |
| ├ `todo.ts` | 待办模型与迁移 |
| ├ `review.ts` | 周统计（含投入和目标）、复盘文件、上一期的下一步、「复制给 AI」的内容 |
| ├ `me.ts` | 「我是谁」的栏目定义和读写 |
| ├ `study.ts` | 学习时间统计：按天、按科目、按周汇总投入，连续天数 |
| ├ `targets.ts` | 每周目标：解析 `me.md` 里的「每周投入」，和实际投入对照 |
| ├ `md.ts` | 每日文件的读写；速记的种类、投入的解析 |
| ├ `memory.ts` | 记忆层：模式账本、各个 AI 的建议的读写 |
| ├ `store.ts` | 操作队列与同步 |
| └ `github.ts` | REST 客户端 |
| `src/components/` | 弹层、滑动行、图表、控件 |
| `src/pages/` | 各页面 |
| `src/styles/` | `tokens.css`（配色、字号、动效）和组件样式 |

界面用 Preact + TSX 编写。
